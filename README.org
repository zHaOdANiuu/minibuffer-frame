* minibuffer-frame

Display the minibuffer in a child frame centered relative to the parent frame.

** Requirements

- [X] Emacs 28.1 or newer

** Installation

[[https://melpa.org/#/minibuffer-frame][Now available MELPA.]]

#+begin_src emacs-lisp
(use-package minibuffer-frame
  :if (display-graphic-p)
  :hook window-setup
#+end_src

If your Emacs version is 31 or above, you can remove the =:if (display-graphic-p)= condition.

** Configuration

Use =M-x customize-group RET minibuffer-frame RET=, or set the variables directly:

| Variable               | Default | Description                               |
|------------------------+---------+-------------------------------------------|
| =minibuffer-frame-width= |   0.5   | Child frame width as a fraction of parent |
| =minibuffer-frame-top=   |   0.3   | Top offset as a fraction of parent        |

The number of completion lines is controlled by Emacs's built-in =completions-max-height= variable. When it is unset, the frame displays one line.
Because the child-frame implementation used here doesn’t work well in Windows terminals; it may behave better on Linux or macOS.

** How it works

- Creates and centers the child frame when the minibuffer is first activated.
- Resizes the frame according to the completion candidates.
- Reuses the same frame for recursive minibuffer sessions.
- Hides the frame after the outermost minibuffer exits.
- Restores focus while the minibuffer is active and supports returning after =other-window=.
